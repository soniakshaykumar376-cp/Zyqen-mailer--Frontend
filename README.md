# Zyqen Technology — AI Mail Automator (Frontend)

The React web dashboard for **Zyqen Technology's** AI-powered candidate outreach and sequence management platform.

## Key Features
- **CSV Candidate Upload:** Parses candidate CSV files (`Name, Email, Role, Skills`) directly in the browser using PapaParse.
- **Human-in-the-Loop Preview:** Lets users inspect and edit AI-generated initial and follow-up emails before launching a campaign.
- **Campaign Controls & Demo Mode:** Launches automated sequences with a 30-second demo timer or standard multi-day delays.
- **Live Queue Tracking:** Displays real-time delivery status (`Draft`, `Active`, `Replied`, `Completed`) and one-click reply pausing.

## Tech Stack
- **Framework & Styling:** React (Vite), Tailwind CSS
- **Libraries:** Axios, PapaParse, Lucide React
